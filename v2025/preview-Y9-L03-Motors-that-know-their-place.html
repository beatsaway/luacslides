6/10

Decode the code

#include <Servo.h>

Servo arm;

int from = 0; // degrees

int to = 180;

int stepDelay = 15; // ms per degree

void setup() {

arm.attach(9);

}

void loop() {

for (int a = from; a <= to; a++) {

arm.write(a);

delay(stepDelay);

}

for (int a = to; a >= from; a--) {

arm.write(a);

delay(stepDelay);

}

}

attach(9) = which pin

Once, in setup(). The library sends the pulses from there.

from and to = the ends

The arm visits every degree between them, in order.

stepDelay = the pace

Milliseconds per degree. Bigger is slower, and it still gets there.

THINK FIRST

Why does a bigger stepDelay move it more slowly?

A longer pause between one degree and the next, so the sweep takes longer.

THE IDEA

A variable lives where you put it

Declared outside loop(), the box survives. Declared inside, it is emptied every time round.

Where you write the line matters as much as what the line says.

DECODE THE CODE

One line that keeps a number

int count = 0;

void setup() {

pinMode(2, INPUT);

Serial.begin(9600);

}

void loop() {

if (digitalRead(2) == HIGH) {

count = count + 1;

Serial.println(count);

delay(250);

}

}

INT COUNT = 0;

Made once, before setup runs. The value stays until you change it or unplug the board.

COUNT = COUNT + 1;

Read the old value, add one, put it back. The right-hand side is worked out first.

DELAY(250);

A crude debounce. Without it, one press is counted many times.

Try it with and without delay(250).

DEBUG · 5 MINUTES

It does not work. Find the fault.

WHAT YOU SEE

Every press prints 1. The number never goes above it.

A

The button is broken

B

count is declared inside loop()

C

Serial.begin is missing

THE FAULT

click to reveal

THE FAULT

int count = 0; is inside loop().

Move it above setup(). A variable declared inside a function is thrown away when that function ends, so every pass starts from zero.

CHECK · ONE QUESTION

Where must a counter be declared so it survives from one loop() to the next?

A

Inside loop()

B

Outside both functions, at the top

C

Inside setup()

THE ANSWER

click to reveal

ANSWER — B

Outside both functions, at the top of the file.

A variable made inside a function lives only while that function runs. At the top of the file it lives for as long as the program.

If you chose another one, say why. That is the useful bit.

STRETCH · IF YOU FINISHED EARLY

If that was easy

COUNT DOWN

Add a second button that subtracts one. Use && to stop it going below zero, and print EMPTY when the count is 0.

FIX THE DOUBLE COUNT PROPERLY

Remove delay(250). Store millis() each time you count, and only count again if 300 ms have passed. That is debouncing, and every real button needs it.

delay() stops the whole program. millis() lets it keep running. That difference matters in Year 9.

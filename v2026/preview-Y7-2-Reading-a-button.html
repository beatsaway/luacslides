A button is wired to pin 2, and nothing else is on pin 2. The button is open. What does digitalRead(2) return?

A

LOW, because nothing is connected

B

HIGH, because nothing is connected

C

It changes at random

THE ANSWER

click to reveal

THE ANSWER

It changes at random.

A pin with nothing holding it is a tiny aerial. It picks up whatever is nearby — a hand, a cable, the mains — and flips between 0 and 1. That is called a floating pin.

Hands up for the one you chose — then we find out.

THE IDEA

An input pin must be held at a known voltage

A resistor ties the pin to 0 V, so it stays LOW until the button pulls it up to 5 V.

10 kΩ is a weak hold: enough to fix the voltage, not enough to waste current.

DECODE THE CODE

Read it, then use it

void setup() {

pinMode(2, INPUT);

pinMode(13, OUTPUT);

Serial.begin(9600);

}

void loop() {

int pressed = digitalRead(2);

digitalWrite(13, pressed);

Serial.println(pressed);

delay(50);

}

PINMODE(2, INPUT)

Faces pin 2 inwards. It listens; it never pushes current out.

DIGITALREAD(2)

Answers one question: is pin 2 nearer 0 V or 5 V? HIGH or LOW.

DIGITALWRITE(13, PRESSED)

Whatever came in goes straight out. Press, and the LED is on.

Serial Monitor: the button at the bottom right.

TEST IT · 5 MINUTES

What success looks like

✓

Hold the button: the LED is on and the Monitor shows 1.

1

✓

Let go: the LED is off and the Monitor shows 0.

0

✓

Untouched, the Monitor scrolls steady 0s — not a mix.

steady 0

WATCH FOR

A mix of 0s and 1s with nothing pressed means the pin is floating: the 10 kΩ is missing or in the wrong row.

It does not work. Find the fault.

WHAT YOU SEE

The LED is on all the time, and the Monitor shows 1, even with nothing pressed.

A

The LED is in backwards

B

The button does not straddle the trench

C

THE FAULT

click to reveal

THE FAULT

The button is shorted across its own legs.

Both legs are in one row, so the switch is permanently closed and pin 2 is permanently at 5 V. Lift the button so it crosses the centre trench, then test both states.

CHECK · ONE QUESTION

Why does pin 2 need the 10 kΩ resistor?

A

To protect the button from too much current

B

To hold the pin at 0 V when the button is open

C

To make the LED brighter

THE ANSWER

click to reveal

ANSWER — B

To hold the pin at 0 V when the button is open.

The button is the only path to 5 V, and it is open. The resistor is the only path to 0 V, and it is always there. Without it the pin floats.

If you chose another one, say why. That is the useful bit.

USE THE BOARD'S OWN RESISTOR

Move the button's 5 V wire to GND, remove the 10 kΩ, and change pinMode(2, INPUT) to INPUT_PULLUP. Now pressed reads LOW. Rewrite the LED line to match.

DEBOUNCE IT

Hold the button and watch the Monitor. Count how many 1s appear for one press. Add a check that ignores a press within 200 ms of the last one.

The board has a resistor inside the chip. INPUT_PULLUP connects it to 5 V instead of to 0 V.

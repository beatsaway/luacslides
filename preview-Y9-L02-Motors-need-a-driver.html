Motors Need a Driver

A pin decides. Something else does the work.

2/10

A fan, a toy car and a washing machine. What do all three need before they turn?

Fan. A blade on a spinning shaft.

Toy car. Small motor, light wheels.

Washing machine. Motor, belt, drum.

None of them is turned by a signal pin.

A motor wants far more current than a pin can give.

3/10

A pin is a signal, not a power supply

20 mA in, 200 mA out

A pin is safe at about 20 mA. A small motor wants ten times that.

A transistor is a switch

A small current at its base lets a big one through.

Base

Where the pin pushes.

Collector

Where the current flows.

Diode

Catches the surge.

The motor's coil kicks back when it stops. The diode gives that a path.

6/10

Decode the code

int topSpeed = 200; // 0 to 255

int rampStep = 5; // how fast it gets there

void setup() {

pinMode(9, OUTPUT);

}

void loop() {

for (int s = 0; s <= topSpeed; s += rampStep) {

analogWrite(9, s);

delay(30);

}

delay(1500);

for (int s = topSpeed; s >= 0; s -= rampStep) {

analogWrite(9, s);

delay(30);

}

delay(1500);

}

topSpeed = the ceiling

255 is fully on. 200 is a little under full.

rampStep = the slope

Add 5 each time and it gets there gently. Add 40 and it lurches.

analogWrite = the average

On for part of each moment, off for the rest. The motor smooths it.

THINK FIRST

Why does the motor keep turning between pulses?

Its own momentum. The blade is already moving.

Quick check: the average

analogWrite(9, 128) does not put half the voltage on the motor.

So why does it turn at about half speed?

Think first. Then raise your hand.

ANSWER

Half the time

The pin is fully on for half of every moment, and the motor's momentum fills the gaps.

Eight inputs

One output

Decode the code

void setup() {

for (int p = 2; p <= 9; p++) {

pinMode(p, INPUT_PULLUP);

}

}

void loop() {

if (digitalRead(2) == LOW) tone(10, 262, 200);

if (digitalRead(3) == LOW) tone(10, 294, 200);

if (digitalRead(4) == LOW) tone(10, 330, 200);

if (digitalRead(5) == LOW) tone(10, 349, 200);

// four more lines, one per key

}

INPUT_PULLUP = no resistor

The pull-up is inside the chip. One wire per key.

Eight ifs = eight keys

The loop asks each key in turn, then plays its note.

One pin, one note

QUICK CHECK

Quick check: eight keys

Every key is wired from its pin to ground.

So why does a pressed key read LOW?

Think first. Then raise your hand.

ANSWER

Pull-up

INPUT_PULLUP holds the pin at 5 V. The key pulls it down to 0 V.

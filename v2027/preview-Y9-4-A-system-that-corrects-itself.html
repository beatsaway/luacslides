THE IDEA · THIS ANSWERS THE QUESTION

Measure, compare, act, repeat

The error is the difference between the target and the measurement. The controller acts on the error.

The lamp settles when the error is small enough to leave alone. Correcting every wobble is how it hunts.

DECODE THE CODE

The loop, in twelve lines

#include <Servo.h>

Servo arm;

int angle = 90;

void setup() {

arm.attach(9);

arm.write(angle);

Serial.begin(9600);

}

void loop() {

int left = analogRead(A0);

int right = analogRead(A1);

if (left > right + 40) angle = angle - 2;

if (right > left + 40) angle = angle + 2;

angle = constrain(angle, 0, 180);

arm.write(angle);

Serial.println(angle);

delay(20);

}

LEFT > RIGHT + 40

A deadband: a small difference is ignored, so the arm does not hunt.

ANGLE = ANGLE - 2

The correction. Small steps, often, beat one big jump.

CONSTRAIN(ANGLE, 0, 180)

Keeps the command inside the servo's travel.

Shade one LDR with your hand.

DEBUG · 5 MINUTES

It does not work. Find the fault.

WHAT YOU SEE

The arm swings past the light and keeps hunting back and forth.

A

The servo is broken

B

The deadband is too small

C

The LDRs are swapped

THE FAULT

click to reveal

THE FAULT

The deadband is too narrow for how much the two sensors disagree.

Widen the deadband (40 → 80), or take smaller steps (2 → 1). A controller that overcorrects oscillates. Every control system has this failure mode.

CHECK · ONE QUESTION

What is the error in a control loop?

A

A mistake in the code

B

The difference between the target and the measurement

C

The delay between readings

THE ANSWER

click to reveal

ANSWER — B

The difference between the target and the measurement.

Error = target − measured. The controller's job is to reduce it. When the error is inside the deadband, the system stops correcting.

If you chose another one, say why. That is the useful bit.

STRETCH · IF YOU FINISHED EARLY

If that was easy

PROPORTIONAL CONTROL

Make the step proportional to the difference: step = (left - right) / 20. Small error, small correction. Watch how much more smoothly it settles.

LOG THE ERROR

Print left, right and angle every pass. Find the moment the error crosses zero. That is the arm arriving.

Proportional control is one line of maths. It is how most real controllers work.
